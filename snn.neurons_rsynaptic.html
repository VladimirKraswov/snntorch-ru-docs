snn.RSynaptic

class snntorch._neurons.rsynaptic.RSynaptic(alpha, beta, V=1.0, all_to_all=True, linear_features=None, conv2d_channels=None, kernel_size=None, threshold=1.0, spike_grad=None, surrogate_disable=False, init_hidden=False, inhibition=False, learn_alpha=False, learn_beta=False, learn_threshold=False, learn_recurrent=True, reset_mechanism='subtract', state_quant=False, output=False, reset_delay=True)[source]

Базовые классы: LIF

Модель рекуррентного нейрона с утечкой и интеграцией второго порядка, учитывающая синаптическую проводимость. Синаптический ток скачкообразно возрастает при поступлении спайка, что вызывает скачок мембранного потенциала. Синаптический ток и мембранный потенциал затухают экспоненциально со скоростями альфа и бета соответственно. Для \(U[T] > U_{\rm thr} ⇒ S[T+1] = 1\).

Если reset_mechanism = “subtract”, то \(U[t+1]\) будет иметь порог вычитаемый из него всякий раз, когда нейрон генерирует спайк:

\[\begin{split}I_{\rm syn}[t+1] = αI_{\rm syn}[t] + V(S_{\rm out}[t] + I_{\rm in}[t+1] \\ U[t+1] = βU[t] + I_{\rm syn}[t+1] - RU_{\rm thr}\end{split}\]

Где \(V(\cdot)\) действует либо как линейный слой, свёрточный оператор, либо как поэлементное произведение на \(S_{\rm out}\).

  • Если all_to_all = “True” и linear_features указано, то \(V(\cdot)\) действует как рекуррентный линейный слой того же размера что и \(S_{\rm out}\).

  • Если all_to_all = “True” и conv2d_channels и kernel_size указаны, то \(V(\cdot)\) действует как рекуррентный сверточный слой с дополнением, чтобы выход соответствовал размеру входа.

  • Если all_to_all = “False”, то \(V(\cdot)\) действует как поэлементный умножитель с \(V\).

  • Если reset_mechanism = “zero”, то \(U[t+1]\) будет установлено в 0

    всякий раз, когда нейрон генерирует спайк:

\[\begin{split}I_{\rm syn}[t+1] = αI_{\rm syn}[t] + VS_{\rm out}[t] + I_{\rm in}[t+1] \\ U[t+1] = βU[t] + I_{\rm syn}[t+1] - R(βU[t] + I_{\rm syn}[t+1])\end{split}\]

  • \(I_{\rm syn}\) - Синаптический ток

  • \(I_{\rm in}\) - Входной ток

  • \(U\) - Мембранный потенциал

  • \(U_{\rm thr}\) - Мембранный порог

  • \(S_{\rm out}\) - Выходной спайк

  • \(R\) - Механизм сброса: если активен, \(R = 1\), в противном случае \(R = 0\)

  • \(α\) - Скорость затухания синаптического тока

  • \(β\) - Скорость затухания мембранного потенциала

  • \(V\) - Явный рекуррентный вес, когда all_to_all=False

Пример:

import torch
import torch.nn as nn
import snntorch as snn

beta = 0.5 # decay rate
V1 = 0.5 # shared recurrent connection
V2 = torch.rand(num_outputs) # unshared recurrent connections

# Define Network
class Net(nn.Module):
    def __init__(self):
        super().__init__()

        # initialize layers
        self.fc1 = nn.Linear(num_inputs, num_hidden)

        # Default RLeaky Layer where recurrent connections
        # are initialized using PyTorch defaults in nn.Linear.
        self.lif1 = snn.RLeaky(beta=beta,
                    linear_features=num_hidden)

        self.fc2 = nn.Linear(num_hidden, num_outputs)

        # each neuron has a single connection back to itself
        # where the output spike is scaled by V.
        # For `all_to_all = True`, V can be shared between
        # neurons (e.g., V1) or unique / unshared between
        # neurons (e.g., V2).
        # V is learnable by default.
        self.lif2 = snn.RLeaky(beta=beta, all_to_all=False, V=V1)

    def forward(self, x):
        # Initialize hidden states at t=0
        spk1, syn1, mem1 = self.lif1.init_rsynaptic()
        spk2, syn2, mem2 = self.lif2.init_rsynaptic()

        # Record output layer spikes and membrane
        spk2_rec = []
        mem2_rec = []

        # time-loop
        for step in range(num_steps):
            cur1 = self.fc1(x)
            spk1, syn1, mem1 = self.lif1(cur1, spk1, syn1, mem1)
            cur2 = self.fc2(spk1)
            spk2, syn2, mem2 = self.lif2(cur2, spk2, syn2, mem2)

            spk2_rec.append(spk2)
            mem2_rec.append(mem2)

        # convert lists to tensors
        spk2_rec = torch.stack(spk2_rec)
        mem2_rec = torch.stack(mem2_rec)

        return spk2_rec, mem2_rec
Параметры:

  • alpha (float или torch.tensor) – скорость затухания синаптического тока. Ограничивается между 0 и 1 во время прямого прохода. Может быть тензором с одним значением (т.е. одинаковая скорость затухания для всех нейронов слоя) или многозначным (один вес на нейрон).

  • beta (float или torch.tensor) – скорость затухания мембранного потенциала. Ограничена между 0 и 1 во время прямого прохода. Может быть одноэлементным тензором (т.е. одинаковая скорость затухания для всех нейронов в слое) или многозначным (один вес на нейрон).

  • V (float или torch.tensor) – рекуррентные веса для масштабирования выходных спайков, используются только если all_to_all=False. По умолчанию 1.

  • all_to_all (bool, необязательный) – позволяет подключать выходные спайки к плотным или свёрточным рекуррентным структурам вместо соединений один-к-одному. По умолчанию True.

  • linear_features (int, необязательный) – Размер каждого выходного образца. Должен быть указан, если all_to_all=True и входные данные одномерны. По умолчанию None

  • conv2d_channels (int, необязательный) – количество каналов в каждом выходном образце. Должно быть указано, если all_to_all=True и входные данные трёхмерные. По умолчанию None

  • kernel_size (int или tuple) – Размер свёрточного ядра. Должен быть указан, если all_to_all=True и входные данные трёхмерные. По умолчанию None

  • порог (float, необязательный) – Порог для \(mem\) достижения для генерации спайка S=1. По умолчанию 1

  • spike_grad (функция суррогатного градиента из snntorch.surrogate, необязательный) – Суррогатный градиент для члена dS/dU. По умолчанию None (соответствует суррогатному градиенту ATan. См. snntorch.surrogate для дополнительных вариантов)

  • surrogate_disable (bool, Optional) – Отключает суррогатные градиенты независимо от spike_grad аргумента. Полезно для совместимости с ONNX. По умолчанию False

  • init_hidden (bool, необязательный) – Создает переменные состояния как переменные экземпляра. По умолчанию False

  • inhibition (bool, необязательный) – Если True, подавляет все спайки, кроме нейрона с наивысшим состоянием. По умолчанию False

  • learn_alpha (bool, необязательный) – Опция для включения обучаемого alpha. По умолчанию False

  • learn_beta (bool, необязательный) – Опция для включения обучаемого beta. По умолчанию False

  • learn_recurrent (bool, необязательный) – опция для включения обучаемых рекуррентных весов. По умолчанию True

  • learn_threshold (bool, необязательный) – опция для включения обучаемого порога. По умолчанию False

  • reset_mechanism (str, необязательный) – Определяет механизм сброса, применяемый к \(mem\) каждый раз при достижении порога. Сброс вычитанием: “subtract”, сброс до нуля: “zero, нет: “none”. По умолчанию “subtract”

  • state_quant (функция квантования из snntorch.quant, необязательный) – Если указано, скрытые состояния \(mem\) и \(syn\) квантуются в допустимое состояние для прямого прохода. По умолчанию False

  • выход (bool, необязательный) – Если True а также init_hidden=True, состояния возвращаются при вызове нейрона. По умолчанию False

Входы: input_, spk_0, syn_0, mem_0

  • input_ формы (batch, input_size): тензор, содержащий входные признаки

  • spk_0 формы (batch, input_size): тензор, содержащий выходные спайковые признаки

  • syn_0 формы (batch, input_size): тензор, содержащий входные признаки

  • mem_0 формы (batch, input_size): тензор, содержащий начальный мембранный потенциал для каждого элемента в пакете.

Выходы: spk_1, syn_1, mem_1

  • spk_1 формы (batch, input_size): тензор, содержащий выходные спайки.

  • syn_1 формы (batch, input_size): тензор, содержащий следующий синаптический ток для каждого элемента в пакете

  • mem_1 формы (batch, input_size): тензор, содержащий следующий мембранный потенциал для каждого элемента в пакете

Обучаемые параметры:

  • RSynaptic.alpha (torch.Tensor) - опциональные обучаемые веса должны быть переданы вручную, форма 1 или (input_size).

  • RSynaptic.beta (torch.Tensor) - опциональные обучаемые веса должны быть переданы вручную, форма 1 или (input_size).

  • RSynaptic.recurrent.weight (torch.Tensor) - опциональные обучаемые веса автоматически генерируются, если all_to_all=True. RSynaptic.recurrent хранит слой nn.Linear или nn.Conv2d слой в зависимости от предоставленных входных аргументов.

  • RSynaptic.V (torch.Tensor) - опциональные обучаемые веса должны быть переданы вручную, форма 1 или (input_size). Он используется только там, где all_to_all=False для рекуррентных соединений один-к-одному.

  • RSynaptic.threshold (torch.Tensor) - опциональные обучаемые пороги должны быть переданы вручную, форма 1 или `` (input_size).
