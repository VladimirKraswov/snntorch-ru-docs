snntorch.spikevision.spikedata

Все наборы данных являются подклассами torch.utils.data.Dataset т.е., они имеют __getitem__ и __len__ реализованные методы. Следовательно, все они могут быть переданы в torch.utils.data.DataLoader который может загружать несколько образцов параллельно, используя torch.multiprocessing воркеров. Например:

nmnist_data = spikevision.data.NMNIST('path/to/nmnist_root/')
data_loader = DataLoader(nmnist_data,
                         batch_size=4,
                         shuffle=True,
                         num_workers=args.nThreads)

За дополнительными примерами по каждому набору данных и его использованию обращайтесь к примерам.

NMNIST

class snntorch.spikevision.spikedata.nmnist.NMNIST(root, train=True, transform=None, target_transform=None, download_and_create=True, num_steps=300, dt=1000)[source]

NMNIST Dataset.

Набор данных Neuromorphic-MNIST (NMNIST) — это спайковая версия исходного покадрового MNIST набора данных.

Загруженный и извлеченный набор данных содержит те же 60000 обучающих и 10000 тестовых образцов, что и набор данных MNIST, и зафиксирован в том же визуальном масштабе, что и исходный набор данных MNIST (28x28 пикселей). Для совместимости с процессом конвертации .hdf5 это количество уменьшается таким образом, чтобы количество образцов для каждого класса было сбалансировано по метке с минимальным количеством образцов (обучение: 5421, тест: 892).

Количество классов: 10

Количество обучающих образцов: 54210

Количество тестовых образцов: 8920

Размерности: [num_steps x 2 x 32 x 32]

  • num_steps: временная размерность событийной видеозаписи

  • 2: количество каналов (on-спайки для увеличения яркости;

off-спайки для уменьшения яркости) * 32x32: пространственные размеры W x H событийной видеозаписи

Для дальнейшего чтения см.:

Orchard, G.; Cohen, G.; Jayawant, A.; and Thakor, N. «Converting Static Image Datasets to Spiking Neuromorphic Datasets Using Saccades», Frontiers in Neuroscience, vol.9, no.437, Oct. 2015.

Пример:

from snntorch.spikevision import spikedata

train_ds = spikedata.NMNIST("data/nmnist", train=True,
num_steps=300, dt=1000)
test_ds = spikedata.NMNIST("data/nmnist", train=False,
num_steps=300, dt=1000)

# by default, each time step is integrated over 1ms, or
dt=1000 microseconds
# dt can be changed to integrate events over a varying number
of time steps
# Note that num_steps should be scaled inversely by the same factor

train_ds = spikedata.NMNIST("data/nmnist", train=True,
num_steps=150, dt=2000)
test_ds = spikedata.NMNIST("data/nmnist", train=False,
num_steps=150, dt=2000)

Набор данных также можно вручную загрузить, извлечь и поместить в root что позволит загрузчику данных обойтись без промежуточных этапов и сразу перейти к созданию hdf5-файла.

Параметры:

  • root (string) – Корневой каталог набора данных, где Train.zip и Test.zip существуют.

  • train (bool, необязательный) – Если True, создает набор данных из Train.zip, иначе из Test.zip

  • transform (callable, необязательный) – Функция/преобразование, которая принимает PIL-изображение и возвращает версию с преобразованиями. По умолчанию ко всем образцам применяется предопределенный набор преобразований для преобразования их в тензор с приоритетом времени (time-first) и правильной ориентацией.

  • target_transform (callable, необязательный) – Функция/преобразование, которая принимает цель и преобразует её.

  • download_and_create (bool, необязательный) – Если True, загружает набор данных из интернета и помещает его в корневой каталог. Если набор данных уже загружен, повторная загрузка не производится.

  • num_steps (int, необязательный) – Количество временных шагов, по умолчанию 300

  • dt (int, необязательный) – Количество временных меток, интегрированных в микросекундах, по умолчанию равно 1000

Загрузчик данных адаптирован из torchneuromorphic изначально авторов Emre Neftci и Clemens Schaefer.

Набор данных распространяется под лицензией Creative Commons Attribution-ShareAlike 4.0. Все права принадлежат исходным авторам.

DVS Gesture Dataset.

Данные были записаны с помощью DVS128. Набор данных содержит 11 жестов рук от 29 субъектов в 3 условиях освещения.

Количество классов: 11

Количество обучающих образцов: 1176

Количество тестовых образцов: 288

Размерности: [num_steps x 2 x 128 x 128]

  • num_steps: временная размерность событийной видеозаписи

  • 2: количество каналов (on-спайки для увеличения яркости;

off-спайки для уменьшения яркости) * 128x128: пространственные размеры W x H событийной видеозаписи

Для дальнейшего чтения см.:

A. Amir, B. Taba, D. Berg, T. Melano, J. McKinstry, C. Di Nolfo, T. Nayak, A. Andreopoulos, G. Garreau, M. Mendoza, J. Kusnitz, M. Debole, S. Esser, T. Delbruck, M. Flickner, and D. Modha, «A Low Power, Fully Event-Based Gesture Recognition System,» 2017 IEEE Conference on Computer Vision and Pattern Recognition (CVPR), Honolulu, HI, 2017.

class snntorch.spikevision.spikedata.shd.SHD(root, train=True, transform=None, target_transform=None, download_and_create=True, num_steps=1000, ds=1, dt=1000)[source]

Spiking Heidelberg Digits Dataset.

Спайки в 700 входных каналах были сгенерированы с помощью искусственной модели улитки, прослушивающей студийные записи произносимых цифр от 0 до 9 на немецком и английском языках.

Количество классов: 20

Количество обучающих образцов: 8156

Количество тестовых образцов: 2264

Размерности: [num_steps x 700]

  • num_steps: временное измерение аудиоканалов

  • 700: количество каналов в модели улитки

Для дальнейшего чтения см.:

Cramer, B., Stradmann, Y., Schemmel, J., and Zenke, F. (2020). The Heidelberg Spiking Data Sets for the Systematic Evaluation of Spiking Neural Networks. IEEE Transactions on Neural Networks and Learning Systems 1–14.

Пример:

from snntorch.spikevision import spikedata

train_ds = spikedata.SHD("data/shd", train=True)
test_ds = spikedata.SHD("data/shd", train=False)

# by default, each time step is integrated over 1ms, or dt=1000
microseconds

train_ds = spikedata.SHD(
"data/shd", train=True, num_steps=500, dt=2000)
test_ds = spikedata.SHD(
"data/shd", train=False, num_steps=500, dt=2000)
