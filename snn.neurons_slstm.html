snn.SLSTM

class snntorch._neurons.slstm.SLSTM(input_size, hidden_size, bias=True, threshold=1.0, spike_grad=None, surrogate_disable=False, init_hidden=False, inhibition=False, learn_threshold=False, reset_mechanism='none', state_quant=False, output=False)[source]

Базовые классы: SpikingNeuron

Спайковый элемент долгой краткосрочной памяти (LSTM). Скрытые состояния представляют собой мембранный потенциал и синаптический ток \(mem, syn\), которые соответствуют скрытому состоянию и состоянию ячейки \(h, c\) в исходной формулировке LSTM.

Ожидается, что входные данные имеют размер \((N, X)\) где \(N\) — это размер батча.

В отличие от модуля LSTM в PyTorch, при каждом вызове ячейки моделируется только один временной шаг.

\[\begin{split}\begin{array}{ll} \\ i_t = \sigma(W_{ii} x_t + b_{ii} + W_{hi} mem_{t-1} + b_{hi}) \\ f_t = \sigma(W_{if} x_t + b_{if} + W_{hf} mem_{t-1} + b_{hf}) \\ g_t = \tanh(W_{ig} x_t + b_{ig} + W_{hg} mem_{t-1} + b_{hg}) \\ o_t = \sigma(W_{io} x_t + b_{io} + W_{ho} mem_{t-1} + b_{ho}) \\ syn_t = f_t ∗ syn_{t-1} + i_t ∗ g_t \\ mem_t = o_t ∗ \tanh(syn_t) \\ \end{array}\end{split}\]

где \(\sigma\) это сигмоидная функция, а ∗ — это произведение Адамара. Выходное состояние \(mem_{t+1}\) подвергается пороговой обработке, чтобы определить,\nгенерируется ли выходной спайк.\nДля соответствия стандартному поведению LSTM-состояний, механизм сброса по умолчанию\nустановлен на reset=”none”, т.е. сброс не применяется. Если это изменено,\nсброс применяется только к \(h_t\).

Пример:

import torch
import torch.nn as nn
import snntorch as snn

beta = 0.5

# Define Network
class Net(nn.Module):
    def __init__(self):
        super().__init__()

        num_inputs = 784
        num_hidden1 = 1000
        num_hidden2 = 10

        spike_grad_lstm = surrogate.straight_through_estimator()

        # initialize layers
        self.slstm1 = snn.SLSTM(num_inputs, num_hidden1,
        spike_grad=spike_grad_lstm)
        self.slstm2 = snn.SLSTM(num_hidden1, num_hidden2,
        spike_grad=spike_grad_lstm)

    def forward(self, x):
        # Initialize hidden states and outputs at t=0
        syn1, mem1 = self.slstm1.init_slstm()
        syn2, mem2 = self.slstm2.init_slstm()

        # Record the final layer
        spk2_rec = []
        mem2_rec = []

        for step in range(num_steps):
            spk1, syn1, mem1 = self.slstm1(x.flatten(1), syn1, mem1)
            spk2, syn2, mem2 = self.slstm2(spk1, syn2, mem2)

            spk2_rec.append(spk2)
            mem2_rec.append(mem2)

        return torch.stack(spk2_rec), torch.stack(mem2_rec)
Параметры:

  • input_size (int) – количество ожидаемых признаков на входе \(x\)

  • hidden_size (int) – количество признаков в скрытом состоянии \(mem\)

  • bias (bool, необязательный) – Если True, добавляет обучаемое смещение к выходу. По умолчанию True

  • порог (float, необязательный) – Порог для \(h\) для достижения, чтобы сгенерировать спайк S=1. По умолчанию 1

  • spike_grad (функция суррогатного градиента из snntorch.surrogate, необязательный) – Суррогатный градиент для члена dS/dU. По умолчанию\nсуррогатный градиент ATan

  • surrogate_disable (bool, Optional) – Отключает суррогатные градиенты независимо от spike_grad аргумента. Полезно для совместимости с ONNX. По умолчанию False

  • learn_threshold (bool, необязательный) – Опция для включения обучаемого порога. По умолчанию False

  • init_hidden (bool, необязательный) – Создает переменные состояния как переменные экземпляра. По умолчанию False

  • inhibition (bool, необязательный) – Если True, подавляет все спайки, кроме нейрона с наивысшим состоянием. По умолчанию False

  • reset_mechanism (str, необязательный) – Определяет механизм сброса, применяемый к \(mem\) каждый раз при достижении порога. Сброс вычитанием: “subtract”, сброс до нуля: “zero, none: “none”. По умолчанию “none”

  • state_quant (функция квантования из snntorch.quant, необязательный) – Если указано, скрытые состояния \(mem\) и \(syn\) квантуются в допустимое состояние для прямого прохода. По умолчанию False

  • выход (bool, необязательный) – Если True а также init_hidden=True, состояния возвращаются при вызове нейрона. По умолчанию False

Inputs: input_, syn_0, mem_0

  • input_ формы (batch, input_size): тензор, содержащий входные признаки

  • syn_0 формы (batch, hidden_size): тензор, содержащий начальный синаптический ток (или состояние ячейки) для каждого элемента в пакете.

  • mem_0 формы (batch, hidden_size): тензор, содержащий начальный мембранный потенциал (или скрытое состояние) для каждого элемента в пакете.

Outputs: spk, syn_1, mem_1

  • spk формы (batch, hidden_size): тензор, содержащий выходной спайк

  • syn_1 формы (batch, hidden_size): тензор, содержащий следующий синаптический ток (или состояние ячейки) для каждого элемента в пакете

  • mem_1 формы (batch, hidden_size): тензор, содержащий следующий мембранный потенциал (или скрытое состояние) для каждого элемента в пакете

Обучаемые параметры:

  • SLSTM.lstm_cell.weight_ih (torch.Tensor) – обучаемые веса входа-скрытого слоя, формы (4*hidden_size, input_size)

  • SLSTM.lstm_cell.weight_ih (torch.Tensor) – обучаемые веса скрытого-скрытого слоя, формы (4*hidden_size, hidden_size)

  • SLSTM.lstm_cell.bias_ih – обучаемое смещение входа-скрытого слоя, формы (4*hidden_size)

  • SLSTM.lstm_cell.bias_hh – обучаемое смещение скрытого-скрытого слоя, формы (4*hidden_size)

Примечание

Хотя рецепт прямого прохода должен быть определен внутри этой функции, следует вызывать Module экземпляр после этого вместо этой, так как первая заботится о запуске зарегистрированных хуков, в то время как последняя молча их игнорирует.
