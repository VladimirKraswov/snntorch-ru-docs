snntorch.surrogate

По умолчанию средства автоматического дифференцирования PyTorch не могут вычислить аналитическую производную графа спайкового нейрона. Дискретная природа спайков затрудняет torch.autograd вычисление градиента, который облегчает обучение. snntorch переопределяет градиент по умолчанию, используя snntorch.surrogate.ATan.

Альтернативные градиенты также доступны в модуле snntorch.surrogate . Они представляют собой либо аппроксимации обратного прохода, либо вероятностные модели срабатывания как функции мембранного потенциала. Также можно реализовать пользовательские суррогатные градиенты, заданные пользователем.

В настоящее время доступные функции суррогатного градиента включают:

  • Sigmoid

  • Fast Sigmoid

  • ATan

  • Straight Through Estimator

  • Triangular

  • SpikeRateEscape

  • Пользовательские суррогатные градиенты

среди нескольких других опций.

Для дальнейшего чтения см.:

E. O. Neftci, H. Mostafa, F. Zenke (2019) Surrogate Gradient Learning in Spiking Neural Networks: Bringing the Power of Gradient-Based Optimization to Spiking Neural Networks. IEEE Signal Processing Magazine, pp. 51-63.

Как использовать суррогатный градиент

Суррогатный градиент должен быть передан как аргумент spike_grad в модель нейрона. Если spike_grad не указан, по умолчанию используется snntorch.surrogate.ATan. В следующем примере мы применяем суррогат быстрого сигмоида к snntorch.Synaptic.

Пример:

import snntorch as snn
from snntorch import surrogate
import torch
import torch.nn as nn

alpha = 0.9
beta = 0.85

# Initialize surrogate gradient
spike_grad1 = surrogate.fast_sigmoid()  # passes default parameters from a closure
spike_grad2 = surrogate.FastSigmoid.apply  # passes default parameters, equivalent to above
spike_grad3 = surrogate.fast_sigmoid(slope=50)  # custom parameters from a closure

# Define Network
class Net(nn.Module):
 def __init__(self):
     super().__init__()

 # Initialize layers, specify the ``spike_grad`` argument
     self.fc1 = nn.Linear(num_inputs, num_hidden)
     self.lif1 = snn.Synaptic(alpha=alpha, beta=beta, spike_grad=spike_grad1)
     self.fc2 = nn.Linear(num_hidden, num_outputs)
     self.lif2 = snn.Synaptic(alpha=alpha, beta=beta, spike_grad=spike_grad3)

 def forward(self, x, syn1, mem1, spk1, syn2, mem2):
     cur1 = self.fc1(x)
     spk1, syn1, mem1 = self.lif1(cur1, syn1, mem1)
     cur2 = self.fc2(spk1)
     spk2, syn2, mem2 = self.lif2(cur2, syn2, mem2)
     return syn1, mem1, spk1, syn2, mem2, spk2

 net = Net().to(device)

Пользовательские суррогатные градиенты

Для гибкости пользователь также может определить пользовательские суррогатные градиенты с помощью custom_surrogate.

Пример:

import snntorch as snn
from snntorch import surrogate
import torch
import torch.nn as nn

beta = 0.9

# Define custom surrogate gradient
 def custom_fast_sigmoid(input_, grad_input, spikes):
     ## The hyperparameter slope is defined inside the function.
     slope = 25
     grad = grad_input / (slope * torch.abs(input_) + 1.0) ** 2
     return grad

 spike_grad = surrogate.custom_surrogate(custom_fast_sigmoid)

# Define Network
class Net(nn.Module):
 def __init__(self):
     super().__init__()

 # Initialize layers
     self.fc1 = nn.Linear(num_inputs, num_hidden)
     self.lif1 = snn.Leaky(beta=beta, spike_grad=spike_grad)
     self.fc2 = nn.Linear(num_hidden, num_outputs)
     self.lif2 = snn.Leaky(beta=beta, spike_grad=spike_grad)

 def forward(self, x, mem1, spk1, mem2):
     cur1 = self.fc1(x)
     spk1, mem1 = self.lif1(cur1, mem1)
     cur2 = self.fc2(spk1)
     spk2, mem2 = self.lif2(cur2, mem2)

     return mem1, spk1, mem2, spk2

 net = Net().to(device)

class snntorch.surrogate.ATan(*args, **kwargs)[source]

Базовые классы: Function

Суррогатный градиент ступенчатой функции Хевисайда.

Прямой проход: Сдвинутая ступенчатая функция Хевисайда.

\[\begin{split}S=\begin{cases} 1 & \text{if U ≥ U$_{\rm thr}$} \\ 0 & \text{if U < U$_{\rm thr}$} \end{cases}\end{split}\]

Обратный проход: Градиент сдвинутой функции арктангенса.

\[\begin{split}S&≈\frac{1}{π}\text{arctan}(πU \frac{α}{2}) \\ \frac{∂S}{∂U}&=\frac{1}{π}\frac{1}{(1+(πU\frac{α}{2})^2)}\end{split}\]

По умолчанию α = 2, и его можно изменить, вызвав surrogate.atan(alpha=2).

Адаптировано из:

W. Fang, Z. Yu, Y. Chen, T. Masquelier, T. Huang, Y. Tian (2021) Incorporating Learnable Membrane Time Constants to Enhance Learning of Spiking Neural Networks. Proc. IEEE/CVF Int. Conf. Computer Vision (ICCV), pp. 2661-2671.

static backward(ctx, grad_output)[source]

Определите формулу для дифференцирования операции с обратным режимом автоматического дифференцирования.

Эта функция должна быть переопределена всеми подклассами. (Определение этой функции эквивалентно определению vjp функции.)

Она должна принимать контекст ctx в качестве первого аргумента, за которым следует столько выходных данных, сколько forward() возвращено (None будет передано для не-тензорных выходов прямой функции), и она должна вернуть столько тензоров, сколько было входов в forward(). Каждый аргумент является градиентом по данному выходу, и каждое возвращаемое значение должно быть градиентом по соответствующему входу. Если вход не является тензором или является тензором, не требующим градиентов, вы можете просто передать None в качестве градиента для этого входа.

Контекст можно использовать для получения тензоров, сохраненных во время прямого прохода. Он также имеет атрибут ctx.needs_input_grad в виде кортежа булевых значений, представляющих, нуждается ли каждый вход в градиенте. Например, backward() будет иметь ctx.needs_input_grad[0] = True если первый вход в forward() нуждается в градиенте, вычисленном по выходу.

Определите прямой проход пользовательской функции autograd.

Эта функция должна быть переопределена всеми подклассами. Существует два способа определить forward:

Использование 1 (Объединенный forward и ctx):

@staticmethod
def forward(ctx: Any, *args: Any, **kwargs: Any) -> Any:
    pass

  • Он должен принимать контекст ctx в качестве первого аргумента, за которым следует любое количество аргументов (тензоров или других типов).

  • Смотрите combining-forward-context для получения дополнительных сведений

Использование 2 (Раздельные forward и ctx):

@staticmethod
def forward(*args: Any, **kwargs: Any) -> Any:
    pass


@staticmethod
def setup_context(ctx: Any, inputs: Tuple[Any, ...], output: Any) -> None:
    pass

  • Forward больше не принимает аргумент ctx.

  • Вместо этого вы также должны переопределить torch.autograd.Function.setup_context() staticmethod для обработки настройки ctx объекта. output является выходом forward, inputs являются кортежем входов в forward.

  • Смотрите extending-autograd для получения дополнительных сведений

Контекст может использоваться для хранения произвольных данных, которые могут быть затем извлечены во время обратного прохода. Тензоры не должны храниться непосредственно на ctx (хотя в настоящее время это не обеспечивается для обратной совместимости). Вместо этого тензоры должны сохраняться либо с помощью ctx.save_for_backward() если они предназначены для использования в backward (эквивалентно, vjp) или ctx.save_for_forward() если они предназначены для использования for in jvp.

class snntorch.surrogate.CustomSurrogate(*args, **kwargs)[source]

Базовые классы: Function

Суррогатный градиент ступенчатой функции Хевисайда.

Прямой проход: Функция оператора спайка.

\[\begin{split}S=\begin{cases} \frac{U(t)}{U} & \text{if U ≥ U$_{\rm thr}$} \\ 0 & \text{if U < U$_{\rm thr}$} \end{cases}\end{split}\]

Обратный проход: Пользовательская функция суррогатного градиента, заданная пользователем.

Пользователь определяет пользовательский суррогатный градиент в отдельной функции. Она передается в статическом методе forward и используется в статическом методе backward.

Аргументами функции пользовательского суррогатного градиента всегда являются входные данные прямого прохода (input_), градиент входных данных (grad_input) и выходные данные прямого прохода (out).

** Важное примечание: Гиперпараметры пользовательской функции суррогатного градиента должны быть определены внутри самой функции. **

Пример:

import torch
import torch.nn as nn
import snntorch as snn
from snntorch import surrogate

def custom_fast_sigmoid(input_, grad_input, spikes):
    ## The hyperparameter slope is defined inside the function.
    slope = 25
    grad = grad_input / (slope * torch.abs(input_) + 1.0) ** 2
    return grad

spike_grad = surrogate.custom_surrogate(custom_fast_sigmoid)

net_seq = nn.Sequential(nn.Conv2d(1, 12, 5),
            nn.MaxPool2d(2),
            snn.Leaky(beta=beta,
                    spike_grad=spike_grad,
                    init_hidden=True),
            nn.Conv2d(12, 64, 5),
            nn.MaxPool2d(2),
            snn.Leaky(beta=beta,
                    spike_grad=spike_grad,
                    init_hidden=True),
            nn.Flatten(),
            nn.Linear(64*4*4, 10),
            snn.Leaky(beta=beta,
                    spike_grad=spike_grad,
                    init_hidden=True,
                    output=True)
            ).to(device)

class snntorch.surrogate.FastSigmoid(*args, **kwargs)[source]

Базовые классы: Function

Суррогатный градиент ступенчатой функции Хевисайда.

Прямой проход: Сдвинутая ступенчатая функция Хевисайда.

\[\begin{split}S=\begin{cases} 1 & \text{if U ≥ U$_{\rm thr}$} \\ 0 & \text{if U < U$_{\rm thr}$} \end{cases}\end{split}\]

Обратный проход: Градиент функции быстрого сигмоида.

\[\begin{split}S&≈\frac{U}{1 + k|U|} \\ \frac{∂S}{∂U}&=\frac{1}{(1+k|U|)^2}\end{split}\]

\(k\) по умолчанию равен 25, и его можно изменить, вызвав surrogate.fast_sigmoid(slope=25).

Адаптировано из:

F. Zenke, S. Ganguli (2018) SuperSpike: Supervised Learning in Multilayer Spiking Neural Networks. Neural Computation, pp. 1514-1541.

Функция спайка по умолчанию для нейрона.

Прямой проход: Сдвинутая ступенчатая функция Хевисайда.

\[\begin{split}S=\begin{cases} 1 & \text{if U ≥ U$_{\rm thr}$} \\ 0 & \text{if U < U$_{\rm thr}$} \end{cases}\end{split}\]

Обратный проход: Градиент спайкового оператора, где подпороговый градиент выбирается из равномерно распределенного шума на интервале \((𝒰\sim[-0.5, 0.5)+μ) σ^2\), где \(μ\) является средним, а \(σ^2\) является дисперсией.

\[\begin{split}S&≈\begin{cases} \frac{U(t)}{U}\Big{|}_{U(t)→U_{\rm thr}} & \text{if U ≥ U$_{\rm thr}$} \\ (𝒰\sim[-0.5, 0.5) + μ) σ^2 & \text{if U < U$_{\rm thr}$} \end{cases} \\ \frac{∂S}{∂U}&=\begin{cases} 1 & \text{if U ≥ U$_{\rm thr}$} \\ (𝒰\sim[-0.5, 0.5) + μ) σ^2 & \text{if U < U$_{\rm thr}$} \end{cases}\end{split}\]

\(μ\) по умолчанию равно 0, и может быть изменено вызовом surrogate.SSO(mean=0).

\(σ^2\) по умолчанию равно 0.2, и может быть изменено вызовом surrogate.SSO(variance=0.5).

Вышеуказанные значения по умолчанию устанавливают градиент в следующее выражение:

\[\begin{split}\frac{∂S}{∂U}&=\begin{cases} 1 & \text{if U ≥ U$_{\rm thr}$} \\ (𝒰\sim[-0.1, 0.1) & \text{if U < U$_{\rm thr}$} \end{cases}\end{split}\]

Определите формулу для дифференцирования операции с обратным режимом автоматического дифференцирования.

Эта функция должна быть переопределена всеми подклассами. (Определение этой функции эквивалентно определению vjp функции.)

Она должна принимать контекст ctx в качестве первого аргумента, за которым следует столько выходных данных, сколько forward() возвращено (None будет передано для не-тензорных выходов прямой функции), и она должна вернуть столько тензоров, сколько было входов в forward(). Каждый аргумент является градиентом по данному выходу, и каждое возвращаемое значение должно быть градиентом по соответствующему входу. Если вход не является тензором или является тензором, не требующим градиентов, вы можете просто передать None в качестве градиента для этого входа.

Контекст можно использовать для получения тензоров, сохраненных во время прямого прохода. Он также имеет атрибут ctx.needs_input_grad в виде кортежа булевых значений, представляющих, нуждается ли каждый вход в градиенте. Например, backward() будет иметь ctx.needs_input_grad[0] = True если первый вход в forward() нуждается в градиенте, вычисленном по выходу.
