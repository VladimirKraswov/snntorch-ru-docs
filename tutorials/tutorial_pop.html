Популяционное кодирование в спайковых нейронных сетях

Введение

Считается, что одни только частотные коды не могут быть доминирующим механизмом кодирования в первичной коре. Одна из нескольких причин заключается в том, что средняя частота разряда нейронов составляет примерно \(0.1-1\) Hz, что намного медленнее времени реакции животных и человека.

Но если мы объединим несколько нейронов и будем считать их спайки вместе, то становится возможным измерить частоту разряда для популяции нейронов за очень короткий промежуток времени. Популяционное кодирование добавляет некоторую убедительность правдоподобию механизмов частотного кодирования.

В этом руководстве вы:

  • Узнайте, как обучать сеть с популяционным кодированием. Вместо назначения одного нейрона на класс, мы расширим это до нескольких нейронов на класс и будем агрегировать их спайки вместе.

import torch, torch.nn as nn
import snntorch as snn

Загрузка данных

Определите переменные для загрузки данных.

batch_size = 128
data_path='/tmp/data/fmnist'
device = torch.device("cuda") if torch.cuda.is_available() else torch.device("mps") if torch.backends.mps.is_available() else torch.device("cpu")

Загрузите набор данных FashionMNIST.

from torch.utils.data import DataLoader
from torchvision import datasets, transforms

# Define a transform
transform = transforms.Compose([
            transforms.Resize((28, 28)),
            transforms.Grayscale(),
            transforms.ToTensor(),
            transforms.Normalize((0,), (1,))])

fmnist_train = datasets.FashionMNIST(data_path, train=True, download=True, transform=transform)
fmnist_test = datasets.FashionMNIST(data_path, train=False, download=True, transform=transform)

# Create DataLoaders
train_loader = DataLoader(fmnist_train, batch_size=batch_size, shuffle=True)
test_loader = DataLoader(fmnist_test, batch_size=batch_size, shuffle=True)

Определите сеть

Давайте сравним производительность пары сетей как с, так и без популяционного кодирования, и обучим их в течение одного временного шага.

from snntorch import surrogate

# network parameters
num_inputs = 28*28
num_hidden = 128
num_outputs = 10
num_steps = 1

# spiking neuron parameters
beta = 0.9  # neuron decay rate
grad = surrogate.fast_sigmoid()

Без популяционного кодирования

Давайте просто используем простую двухслойную плотную спайковую сеть.

net = nn.Sequential(nn.Flatten(),
                    nn.Linear(num_inputs, num_hidden),
                    snn.Leaky(beta=beta, spike_grad=grad, init_hidden=True),
                    nn.Linear(num_hidden, num_outputs),
                    snn.Leaky(beta=beta, spike_grad=grad, init_hidden=True, output=True)
                    ).to(device)

С популяционным кодированием

Вместо 10 выходных нейронов, соответствующих 10 выходным классам, мы будем использовать 500 выходных нейронов. Это означает, что каждому выходному классу случайным образом назначается 50 нейронов.

pop_outputs = 500

net_pop = nn.Sequential(nn.Flatten(),
                        nn.Linear(num_inputs, num_hidden),
                        snn.Leaky(beta=beta, spike_grad=grad, init_hidden=True),
                        nn.Linear(num_hidden, pop_outputs),
                        snn.Leaky(beta=beta, spike_grad=grad, init_hidden=True, output=True)
                        ).to(device)

Обучение

Без популяционного кодирования

Определите оптимизатор и функцию потерь. Здесь мы используем MSE Count Loss, которая подсчитывает общее количество выходных спайков в конце запуска симуляции.

Правильный класс имеет целевую вероятность разряда 100%, а неправильные классы установлены в 0%.

import snntorch.functional as SF

optimizer = torch.optim.Adam(net.parameters(), lr=2e-3, betas=(0.9, 0.999))
loss_fn = SF.mse_count_loss(correct_rate=1.0, incorrect_rate=0.0)

Мы также определим простую функцию точности теста, которая предсказывает правильный класс на основе нейрона с наибольшим количеством спайков.

from snntorch import utils

def test_accuracy(data_loader, net, num_steps, population_code=False, num_classes=False):
  with torch.no_grad():
    total = 0
    acc = 0
    net.eval()

    data_loader = iter(data_loader)
    for data, targets in data_loader:
      data = data.to(device)
      targets = targets.to(device)
      utils.reset(net)
      spk_rec, _ = net(data)

      if population_code:
        acc += SF.accuracy_rate(spk_rec.unsqueeze(0), targets, population_code=True, num_classes=10) * spk_rec.size(1)
      else:
        acc += SF.accuracy_rate(spk_rec.unsqueeze(0), targets) * spk_rec.size(1)

      total += spk_rec.size(1)

  return acc/total

Давайте запустим цикл обучения. Обратите внимание, что мы обучаем только в течение \(1\) временного шага. Т.е., каждый нейрон имеет возможность разрядиться только один раз. В результате мы не можем ожидать, что сеть будет работать слишком хорошо здесь.

from snntorch import backprop

num_epochs = 5

# training loop
for epoch in range(num_epochs):

    avg_loss = backprop.BPTT(net, train_loader, num_steps=num_steps,
                          optimizer=optimizer, criterion=loss_fn, time_var=False, device=device)

    print(f"Epoch: {epoch}")
    print(f"Test set accuracy: {test_accuracy(test_loader, net, num_steps)*100:.3f}%\n")

    >> Epoch: 0
    >> Test set accuracy: 59.421%

    >> Epoch: 1
    >> Test set accuracy: 61.889%

Хотя существуют способы улучшить производительность за один временной шаг, например, путем применения потерь к мембранному потенциалу, один временной шаг является чрезвычайно сложным для конкурентного обучения сети с использованием частотных кодов.

С популяционным кодированием

Давайте изменим функцию потерь, чтобы указать, что популяционное кодирование должно быть включено. Мы также должны указать количество классов. Это означает, что всего будет \(50~neurons~per~class~=~500~neurons~/~10~classes\).

loss_fn = SF.mse_count_loss(correct_rate=1.0, incorrect_rate=0.0, population_code=True, num_classes=10)
optimizer = torch.optim.Adam(net_pop.parameters(), lr=2e-3, betas=(0.9, 0.999))

num_epochs = 5

# training loop
for epoch in range(num_epochs):

    avg_loss = backprop.BPTT(net_pop, train_loader, num_steps=num_steps,
                            optimizer=optimizer, criterion=loss_fn, time_var=False, device=device)

    print(f"Epoch: {epoch}")
    print(f"Test set accuracy: {test_accuracy(test_loader, net_pop, num_steps, population_code=True, num_classes=10)*100:.3f}%\n")

    >> Epoch: 0
    >> Test set accuracy: 80.501%

    >> Epoch: 1
    >> Test set accuracy: 82.690%

Несмотря на то, что мы обучаем только на одном временном шаге, введение дополнительных выходных нейронов сразу же позволило улучшить производительность.

Заключение

Прирост производительности от популяционного кодирования может начать угасать по мере увеличения количества временных шагов. Но это также может быть предпочтительнее увеличения временных шагов, так как PyTorch оптимизирован для обработки матрично-векторных произведений, а не последовательных операций шаг за шагом во времени.
