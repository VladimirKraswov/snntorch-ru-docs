Ускорение snnTorch на IPU

Учебное пособие написано Jason K. Eshraghian и Винсент Сан

Серия учебных пособий snnTorch основана на следующей статье. Если вы считаете эти ресурсы или код полезными в своей работе, пожалуйста, укажите следующий источник:

Введение

Спайковые нейронные сети (SNN) достигли улучшения на порядки с точки зрения энергопотребления и задержки при выполнении инференса с нагрузками глубокого обучения. Но по иронии судьбы использование обратного распространения ошибки для обучения SNN становится более затратным, чем для неспайковых сетей, при обучении на CPU и GPU. Необходимо учитывать дополнительное временное измерение, и сложность по памяти линейно возрастает со временем, когда сеть обучается с помощью алгоритма обратного распространения во времени.

Альтернативная сборка snnTorch оптимизирована для процессоров Intelligence Processing Units (IPU) компании Graphcore . IPU — это специализированные ускорители, разработанные для нагрузок глубокого обучения, и используют параллелизм MIMD (множество инструкций, множество данных), запуская отдельные потоки обработки на небольших блоках данных. Это идеально подходит для разделов уравнений динамических состояний спайковых нейронов, которые должны обрабатываться последовательно и не могут быть векторизованы.Узнайте, как обучить SNN с ускорением с помощью IPU.

В этом руководстве вы:

  • Убедитесь, что установлены актуальные версии

и Poplar SDK установлены. poptorch Обратитесь к документации Graphcore для получения инструкций по установке.

Установите snntorch-ipu в среде, в которой не установлен snntorch предварительно установлен, чтобы избежать конфликтов пакетов:

!pip install snntorch-ipu

Импортируйте необходимые пакеты Python:

import torch, torch.nn as nn
import popart, poptorch
import snntorch as snn
import snntorch.functional as SF

Загрузка данных

Загрузите набор данных MNIST.

from torch.utils.data import DataLoader
from torchvision import datasets, transforms

batch_size = 128
data_path='/tmp/data/mnist'

# Define a transform
transform = transforms.Compose([
            transforms.Resize((28, 28)),
            transforms.Grayscale(),
            transforms.ToTensor(),
            transforms.Normalize((0,), (1,))])

mnist_train = datasets.MNIST(data_path, train=True, download=True, transform=transform)
mnist_test = datasets.MNIST(data_path, train=False, download=True, transform=transform)

# Train using full precision 32-flt
opts = poptorch.Options()
opts.Precision.halfFloatCasting(poptorch.HalfFloatCastingBehavior.HalfUpcastToFloat)

# Create DataLoaders
train_loader = poptorch.DataLoader(options=opts, dataset=mnist_train, batch_size=batch_size, shuffle=True, num_workers=20)
test_loader = poptorch.DataLoader(options=opts, dataset=mnist_test, batch_size=batch_size, shuffle=True, num_workers=20)

Определите сеть

Давайте смоделируем нашу сеть в течение 25 временных шагов, используя медленную скорость затухания состояния для наших спайковых нейронов:

num_steps = 25
beta = 0.9

Теперь мы построим стандартную модель SNN. При обучении на IPU обратите внимание, что функция потерь должна быть обернута внутри класса модели. Полный код будет выглядеть так:

class Model(torch.nn.Module):
def __init__(self):
    super().__init__()

    num_inputs = 784
    num_hidden = 1000
    num_outputs = 10

    self.fc1 = nn.Linear(num_inputs, num_hidden)
    self.lif1 = snn.Leaky(beta=beta)
    self.fc2 = nn.Linear(num_hidden, num_output)
    self.lif2 = snn.Leaky(beta=beta)

    # Cross-Entropy Spike Count Loss
    self.loss_fn = SF.ce_count_loss()

def forward(self, x, labels=None):
    mem1 = self.lif1.init_leaky()
    mem2 = self.lif2.init_leaky()

    spk2_rec = []
    mem2_rec = []

    for step in range(num_steps):
        cur1 = self.fc1(x.view(batch_size,-1))
        spk1, mem1 = self.lif1(cur1, mem1)
        cur2 = self.fc2(spk1)
        spk2, mem2 = self.lif2(cur2, mem2)

        spk2_rec.append(spk2)
        mem2_rec.append(mem2)

    spk2_rec = torch.stack(spk2_rec)
    mem2_rec = torch.stack(mem2_rec)

    if self.training:
        return spk2_rec, poptorch.identity_loss(self.loss_fn(mem2_rec, labels), "none")
    return spk2_rec

Давайте быстро разберем это.

Построение модели такое же, как во всех предыдущих учебных пособиях. Мы применяем узлы спайковых нейронов в конце каждого полносвязного слоя:

self.fc1 = nn.Linear(num_inputs, num_hidden)
self.lif1 = snn.Leaky(beta=beta)
self.fc2 = nn.Linear(num_hidden, num_output)
self.lif2 = snn.Leaky(beta=beta)

По умолчанию суррогатный градиент спайковых нейронов будет прямой оценкой (straight-through estimator). Также доступны варианты Fast Sigmoid и Sigmoid, если вы предпочитаете использовать их:

from snntorch import surrogate

self.lif1 = snn.Leaky(beta=beta, spike_grad = surrogate.fast_sigmoid())

Функция потерь будет подсчитывать общее количество спайков от каждого выходного нейрона и применять кросс-энтропийные потери (Cross Entropy Loss):

self.loss_fn = SF.ce_count_loss()

Теперь определим прямой проход. Инициализируйте скрытое состояние каждого спайкового нейрона, вызвав следующие функции:

mem1 = self.lif1.init_leaky()
mem2 = self.lif2.init_leaky()

Затем запустите цикл for для моделирования SNN в течение 25 временных шагов. Входные данные уплощаются с помощью .view(batch_size, -1) чтобы сделать их совместимыми с полносвязным входным слоем.

for step in range(num_steps):
    cur1 = self.fc1(x.view(batch_size,-1))
    spk1, mem1 = self.lif1(cur1, mem1)
    cur2 = self.fc2(spk1)
    spk2, mem2 = self.lif2(cur2, mem2)

Потери применяются с помощью функции poptorch.identity_loss(self.loss_fn(mem2_rec, labels), "none").

Обучение на IPU

Теперь полный цикл обучения выполняется в течение 10 эпох. Обратите внимание, что оптимизатор вызывается из poptorch. В остальном процесс обучения практически такой же, как при типичном использовании snnTorch.

net = Model()
optimizer = poptorch.optim.Adam(net.parameters(), lr=0.001, betas=(0.9, 0.999))

poptorch_model = poptorch.trainingModel(net, options=opts, optimizer=optimizer)

epochs = 10
for epoch in tqdm(range(epochs), desc="epochs"):
    correct = 0.0

    for i, (data, labels) in enumerate(train_loader):
        output, loss = poptorch_model(data, labels)

        if i % 250 == 0:
            _, pred = output.sum(dim=0).max(1)
            correct = (labels == pred).sum().item()/len(labels)

            # Accuracy on a single batch
            print("Accuracy: ", correct)

Модель будет сначала скомпилирована, после чего начнется процесс обучения. Точность будет выводиться для отдельных мини-пакетов на обучающем наборе, чтобы сохранить это учебное пособие быстрым и минимальным.
