snntorch.export_nir

snntorch.export_nir модуль, который обеспечивает кросс-совместимость с другими библиотеками SNN путем преобразования моделей snnTorch в нейроморфное промежуточное представление (NIR) и теперь поддерживает экспорт рекуррентных слоев, таких как snntorch.RLeaky и snntorch.RSynaptic.

snntorch.export_nir.export_to_nir(module: Module, sample_data: Tensor, model_name: str = 'snntorch', model_fwd_args=[], ignore_dims=[]) → NIRNode[source]

Преобразование модуля snnTorch в нейроморфное промежуточное представление (NIR). Эта функция использует nirtorch для извлечения вычислительного графа модуля torch, а метод _extract_snntorch_module используется для преобразования каждого модуля в графе в соответствующий модуль NIR.

NIR — это графовое представление импульсной нейронной сети, которое можно использовать для переноса сети на различные нейроморфные аппаратные и программные платформы.

Пример:

import snntorch as snn
import torch
from snntorch.export_nir import export_to_nir

lif1 = snn.Leaky(beta=0.9, init_hidden=True)
lif2 = snn.Leaky(beta=0.9, init_hidden=True, output=True)

net = torch.nn.Sequential(
    torch.nn.Flatten(),
    torch.nn.Linear(784, 500),
    lif1,
    torch.nn.Linear(500, 10),
    lif2
)

sample_data = torch.randn(1, 784)
nir_graph = export_to_nir(net, sample_data)
Параметры:

  • модуль (torch.nn.Module) – Модель сети (обернутая в контейнер Sequential или в виде класса)

  • sample_data (torch.Tensor) – Пример входных данных для сети

  • model_name (str, необязательный) – Имя модели

  • model_fwd_args (list, необязательный) – Аргументы, передаваемые функции forward модели

  • ignore_dims (list, необязательный) – Список размерностей, игнорируемых при извлечении NIR

Возвращает:

возвращает граф NIR

Тип возврата:

nir.NIRNode
