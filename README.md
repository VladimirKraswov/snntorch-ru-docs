# snnTorch documentation in Russian

Неофициальный русский перевод актуальной документации snnTorch.

- Оригинал: <https://snntorch.readthedocs.io/en/latest/>
- Версия документации: `latest`, `snntorch 0.9.4`
- Дата зеркалирования: 2026-05-17
- Лицензия документации: CC BY-SA 3.0

Этот репозиторий предназначен для публикации статической HTML-копии через
GitHub Pages. Файл `.nojekyll` нужен, чтобы GitHub Pages корректно отдавал
каталоги Sphinx/ReadTheDocs вида `_static`.
