Вклад

Приветствуются любые вклады! Мы очень ценим вашу помощь. Любая мелочь полезна, и авторство всегда будет указано.

Вы можете внести свой вклад разными способами:

Типы вкладов

Сообщить об ошибках

Сообщайте об ошибках по адресу https://github.com/jeshraghian/snntorch/issues.

Если вы сообщаете об ошибке, пожалуйста, укажите:

  • Название и версию вашей операционной системы.

  • Любые детали о вашей локальной настройке, которые могут помочь в устранении неполадок.

  • Подробные шаги для воспроизведения ошибки.

Исправить ошибки

Просмотрите задачи GitHub с меткой 'bug' и 'help wanted' — они открыты для всех желающих.

Реализовать функции

Просмотрите задачи GitHub с меткой 'enhancement' и 'help wanted' — они открыты для всех желающих.

Написать документацию

snntorch всегда нуждается в дополнительной документации: будь то в официальной документации snntorch, в docstrings, или даже в интернете в виде постов в блогах, статей и т.д.

Отправить отзыв

Лучший способ отправить отзыв — создать задачу по адресу https://github.com/jeshraghian/snntorch/issues.

Если вы предлагаете новую функцию:

  • Подробно объясните, как она будет работать.

  • Старайтесь максимально сузить область, чтобы упростить реализацию.

  • Помните, что это проект, управляемый добровольцами, и вклады приветствуются :)

Начните работу!

Готовы внести свой вклад? Вот как настроить snntorch для локальной разработки.

  1. Сделайте форк snntorch репозитория на GitHub.

  2. Клонируйте свой форк локально:

    $ git clone git@github.com:your_name_here/snntorch.git

  3. Установите локальную копию в virtualenv. Предполагается, что у вас установлен virtualenvwrapper; вот как настроить форк для локальной разработки:

    $ mkvirtualenv snntorch
$ cd snntorch/
$ python setup.py develop

  4. Создайте ветку для локальной разработки:

    $ git checkout -b name-of-your-bugfix-or-feature

    Теперь вы можете вносить изменения локально.

  5. Когда вы закончите вносить изменения, убедитесь, что они проходят проверку flake8 и тесты. Кроме того, убедитесь, что ваш код отформатирован с помощью black:

    $ flake8 snntorch tests
$ black snntorch tests
$ python setup.py test or pytest

    Чтобы установить flake8, black и tox, просто выполните pip install в вашем virtualenv. При желании можно добавить предварительные хуки (pre-commit hooks) для flake8 и black, чтобы упростить форматирование.

  6. Зафиксируйте изменения (commit) и отправьте ветку на GitHub:

    $ git add .
$ git commit -m "Your detailed description of your changes."
$ git push origin name-of-your-bugfix-or-feature

  7. Создайте pull request через веб-сайт GitHub.

Рекомендации по pull request

Перед отправкой pull request проверьте, соответствует ли он следующим рекомендациям:

  1. Pull request должен включать тесты.

  2. Если pull request добавляет функциональность, документация должна быть обновлена. Поместите новую функциональность в функцию с docstring и добавьте описание функции в список в README.rst.

  3. Pull request должен работать для Python 3.9, 3.10, 3.11 и PyPy. Проверьте https://github.com/jeshraghian/snntorch/actions и убедитесь, что тесты проходят для всех поддерживаемых версий Python.

Советы

Чтобы запустить подмножество тестов:

$ pytest tests.test_snntorch

Развертывание

Напоминание для мейнтейнеров о том, как выполнить развертывание. Убедитесь, что все ваши изменения зафиксированы (включая запись в HISTORY.rst). Затем выполните:

$ bump2version patch # possible: major / minor / patch
$ git push
$ git push --tags

Затем GitHub Actions развернет пакет на PyPI, если тесты пройдут успешно.
