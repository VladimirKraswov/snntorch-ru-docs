Использование экземплярных переменных требуется только при вызове встроенных методов обратного распространения в

snntorch.backprop представляет собой модуль, реализующий различные алгоритмы обратного распространения, зависящие от времени. Каждый метод выполняет прямой проход, обратный проход и обновление параметров за все временные шаги одной строкой кода.

Как использовать backprop

Для использования snntorch.backprop сначала необходимо построить сеть, определить критерий потерь и выбрать оптимизатор. При инициализации нейронов установите init_hidden=True. Это позволяет методам в snntorch.backprop автоматически очищать скрытые переменные состояния, а также отсоединять их от графа вычислений при необходимости.

Примечание

Первое измерение входных данных data считается временем. Встроенные функции обратного распространения проходят по первому измерению data по умолчанию. Для инвариантных во времени входных данных установите time_var=False.

Пример:

net = Net().to(device)
optimizer = torch.optim.Adam(net.parameters(), lr=lr, betas=betas)
criterion = nn.CrossEntropyLoss()

# Time-variant input data
for input, target in dataset:
   loss = BPTT(net, input, target, num_steps, batch_size, optimizer, criterion)

# Time-invariant input data
for input, targets in dataset:
   loss = BPTT(net, input, target, num_steps, batch_size, optimizer, criterion, time_var=False)

Обратное распространение через время. Слои LIF требуют параметр init_hidden = True. Прямой проход применяется для каждого временного шага, пока накапливаются потери. Обратный проход и обновление параметров применяются только в конце каждой последовательности временных шагов. BPTT эквивалентен TBPTT для случая, когда num_steps = K.

Пример:

import snntorch as snn
import snntorch.functional as SF
from snntorch import utils
from snntorch import backprop
import torch
import torch.nn as nn

lif1 = snn.Leaky(beta=0.9, init_hidden=True)
lif2 = snn.Leaky(beta=0.9, init_hidden=True, output=True)

net = nn.Sequential(nn.Flatten(),
                    nn.Linear(784,500),
                    lif1,
                    nn.Linear(500, 10),
                    lif2).to(device)

device = torch.device("cuda") if torch.cuda.is_available() else
torch.device("cpu")
num_steps = 100

optimizer = torch.optim.Adam(net.parameters(), lr=5e-4,
betas=(0.9, 0.999))
loss_fn = SF.mse_count_loss()
reg_fn = SF.l1_rate_sparsity()


# train_loader is of type torch.utils.data.DataLoader
# if input data is time-static, set time_var=False, and specify
# num_steps.
# if input data is time-varying, set time_var=True and do not
# specify num_steps.

for epoch in range(5):
    loss = backprop.RTRL(net, train_loader, optimizer=optimizer,
    criterion=loss_fn, num_steps=num_steps, time_var=False,
    regularization=reg_fn, device=device)
Параметры:

  • net (torch.nn.modules.container.Sequential) – Модель сети (либо обёрнутая в контейнер Sequential, либо как класс)

  • dataloader (torch.utils.data.DataLoader) – DataLoader, содержащий данные и цели

  • optimizer (torch.optim) – Используемый оптимизатор, например, torch.optim.adam.Adam

  • criterion (snn.functional.LossFunctions) – Критерий потерь из snntorch.functional, например, snn.functional.mse_count_loss()

  • num_steps (int, необязательный) – Количество временных шагов. Не нужно указывать, если time_var=True.

  • time_var (Bool, необязательный) – Установите в True если входные данные изменяются во времени [T x B x dims]. В противном случае установите false, если входные данные постоянны во времени [B x dims], по умолчанию True

  • time_first (Bool, необязательный) – Установите в False если первое измерение данных не является временем [B x T x dims] И также должно быть переставлено в [T x B x dims], по умолчанию True

  • regularization (функция регуляризации snn.functional, необязательный) – Опция добавления члена регуляризации к функции потерь

  • device (string, необязательный) – Укажите либо “cuda”, либо “cpu”, по умолчанию “cpu”

betas=(0.9, 0.999))

# train_loader is of type torch.utils.data.DataLoader
# if input data is time-static, set time_var=False, and specify

# backprop is automatically applied every K=40 time steps
