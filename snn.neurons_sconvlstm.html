snn.SConv2dLSTM

class snntorch._neurons.sconv2dlstm.SConv2dLSTM(in_channels, out_channels, kernel_size, bias=True, max_pool=0, avg_pool=0, threshold=1.0, spike_grad=None, surrogate_disable=False, init_hidden=False, inhibition=False, learn_threshold=False, reset_mechanism='none', state_quant=False, output=False)[source]

Базовые классы: SpikingNeuron

Спайковая двумерная сверточная LSTM-ячейка.\nСкрытые состояния — это мембранный потенциал и синаптический ток. \(mem, syn\), которые соответствуют скрытому состоянию и состоянию ячейки \(h, c\) в исходной формулировке LSTM.

Ожидается, что входные данные имеют размер \((N, C_{in}, H_{in}, W_{in})\) где \(N\) — это размер батча.

В отличие от модуля LSTM в PyTorch, моделируется только один временной шаг каждый\nраз при вызове ячейки.

\[\begin{split}\begin{array}{ll} \\ i_t = \sigma(W_{ii} ⋆ x_t + b_{ii} + W_{hi} ⋆ mem_{t-1} + b_{hi}) \\ f_t = \sigma(W_{if} ⋆ x_t + b_{if} + W_{hf} mem_{t-1} + b_{hf}) \\ g_t = \tanh(W_{ig} ⋆ x_t + b_{ig} + W_{hg} ⋆ mem_{t-1} + b_{hg}) \\ o_t = \sigma(W_{io} ⋆ x_t + b_{io} + W_{ho} ⋆ mem_{t-1} + b_{ho}) \\ syn_t = f_t ∗ c_{t-1} + i_t ∗ g_t \\ mem_t = o_t ∗ \tanh(syn_t) \\ \end{array}\end{split}\]

где \(\sigma\) — это сигмоидная функция, ⋆ — это двумерный\nоператор взаимной корреляции, а ∗ — это произведение Адамара.\nВыходное состояние \(mem_{t+1}\) подвергается пороговой обработке, чтобы определить,\nгенерируется ли выходной спайк.\nДля соответствия стандартному поведению LSTM-состояний, механизм сброса по умолчанию\nустановлен на reset=”none”, т.е. сброс не применяется. Если это изменено,\nсброс применяется только к \(mem_t\).

Также доступны опции применения максимального объединения или среднего объединения к состоянию \(mem_t\) Также доступны. Обратите внимание, что предпочтительнее применять\nобъединение к состоянию, а не к спайку, так как не имеет смысла\nприменять объединение к активациям из 1 и 0, что может привести к случайному\nразрыву связей (tie-breaking).

Дополнение применяется автоматически для обеспечения согласованных размеров\nскрытых состояний от одного временного шага к следующему.

На данный момент stride != 1 не поддерживается.

Пример:

import torch
import torch.nn as nn
import snntorch as snn


# Define Network
class Net(nn.Module):
    def __init__(self):
        super().__init__()

        in_channels = 1
        out_channels = 8
        kernel_size = 3
        max_pool = 2
        avg_pool = 2
        flattened_input = 49 * 16
        num_outputs = 10
        beta = 0.5

        spike_grad_lstm = snn.surrogate.straight_through_estimator()
        spike_grad_fc = snn.surrogate.fast_sigmoid(slope=5)

        # initialize layers
        self.sclstm1 = snn.SConv2dLSTM(
            in_channels,
            out_channels,
            kernel_size,
            max_pool=max_pool,
            spike_grad=spike_grad_lstm,
        )
        self.sclstm2 = snn.SConv2dLSTM(
            out_channels,
            out_channels,
            kernel_size,
            avg_pool=avg_pool,
            spike_grad=spike_grad_lstm,
        )
        self.fc1 = nn.Linear(flattened_input, num_outputs)
        self.lif1 = snn.Leaky(beta=beta, spike_grad=spike_grad_fc)

    def forward(self, x):
        # Initialize hidden states and outputs at t=0
        syn1, mem1 = self.lif1.init_sconv2dlstm()
        syn2, mem2 = self.lif1.init_sconv2dlstm()
        mem3 = self.lif3.init_leaky()

        # Record the final layer
        spk3_rec = []
        mem3_rec = []

        # Number of steps assuming x is [N, T, C, H, W] with
        # N = Batches, T = Time steps, C = Channels,
        # H = Height, W = Width
        num_steps = x.size()[1]

        for step in range(num_steps):
            x_step = x[:, step, :, :, :]
            spk1, syn1, mem1 = self.sclstm1(x_step, syn1, mem1)
            spk2, syn2, mem2 = self.sclstm2(spk1, syn2, mem2)
            cur = self.fc1(spk2.flatten(1))
            spk3, mem3 = self.lif1(cur, mem3)

            spk3_rec.append(spk3)
            mem3_rec.append(mem3)

        return torch.stack(spk3_rec), torch.stack(mem3_rec)
Параметры:

  • in_channels (int) – количество входных каналов

  • kernel_size (int, tuple, или list) – Размер сверточного ядра

  • bias (bool, необязательный) – Если True, добавляет обучаемое смещение к выходу. По умолчанию True

  • max_pool (int, tuple, или list, необязательный) – Применяет максимальное объединение к скрытому состоянию \(mem\) до пороговой обработки, если указано. По умолчанию 0

  • avg_pool (int, tuple, или list, необязательный) – Применяет среднее объединение к скрытому состоянию \(mem\) до пороговой обработки, если указано. По умолчанию 0

  • порог (float, необязательный) – Порог для \(mem\) достижения для генерации спайка S=1. По умолчанию 1

  • spike_grad (функция суррогатного градиента из snntorch.surrogate, необязательный) – Суррогатный градиент для члена dS/dU. По умолчанию\nсуррогатный градиент ATan

  • surrogate_disable (bool, Optional) – Отключает суррогатные градиенты независимо от spike_grad аргумента. Полезно для совместимости с ONNX. По умолчанию False

  • learn_threshold (bool, необязательный) – Опция для включения обучаемого порога. По умолчанию False

  • init_hidden (bool, необязательный) – Создает переменные состояния как переменные экземпляра. По умолчанию False

  • inhibition (bool, необязательный) – Если True, подавляет все спайки, кроме нейрона с наивысшим состоянием. По умолчанию False

  • reset_mechanism (str, необязательный) – Определяет механизм сброса, применяемый к \(mem\) каждый раз при достижении порога. Сброс вычитанием: “subtract”, сброс до нуля: “zero, none: “none”. По умолчанию “none”

  • state_quant (функция квантования из snntorch.quant, необязательный) – Если указано, скрытые состояния \(mem\) и \(syn\) квантуются в допустимое состояние для прямого прохода. По умолчанию False

  • выход (bool, необязательный) – Если True а также init_hidden=True, состояния возвращаются при вызове нейрона. По умолчанию False

Inputs: input_, syn_0, mem_0

  • input_ формы (batch, in_channels, H, W): tensor содержащий входные признаки

  • syn_0 формы (batch, out_channels, H, W): tensor содержащий начальный синаптический ток (или состояние ячейки) для каждого элемента в батче.

  • mem_0 формы (batch, out_channels, H, W): tensor содержащий начальный мембранный потенциал (или скрытое состояние) для каждого элемента в батче.

Outputs: spk, syn_1, mem_1

  • spk формы (batch, out_channels, H/pool, W/pool): tensor содержащий выходной спайк (avg_pool и max_pool масштабируют, если значение больше 0.)

  • syn_1 формы (batch, out_channels, H, W): tensor содержащий следующий синаптический ток (или состояние ячейки) для каждого элемента в батче

  • mem_1 формы (batch, out_channels, H, W): tensor содержащий следующий мембранный потенциал (или скрытое состояние) для каждого элемента в батче

Обучаемые параметры:

  • SConv2dLSTM.conv.weight (torch.Tensor) - обучаемые веса, формы ((in_channels + out_channels), 4*out_channels, kernel_size).
