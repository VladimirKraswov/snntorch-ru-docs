snntorch.utils

snntorch.utils содержит несколько вспомогательных функций для работы с наборами данных.

snntorch.utils.data_subset(dataset, subset, idx=0)[source]

Разделить набор данных на коэффициент 1/subset без удаления доступа к атрибутам данных и целей.

Пример:

from snntorch import utils
from torchvision import datasets

data_path = "path/to/data"
subset = 10

#  Download MNIST training set
mnist_train = datasets.MNIST(data_path, train=True, download=True)
print(len(mnist_train))
>>> 60000

#  Reduce size of MNIST training set
utils.data_subset(mnist_train, subset)
print(len(mnist_train))
>>> 6000
Параметры:

  • dataset (torchvision dataset) – Dataset

  • subset (int) – Коэффициент уменьшения набора данных

  • idx (int, необязательный) – Какое подмножество обучающего и тестового наборов индексировать, по умолчанию 0

Возвращает:

Partitioned dataset

Тип возврата:

list of torch.utils.data

snntorch.utils.reset(net)[source]

Проверяет типы нейронов LIF, содержащихся в сети. Сбрасывает их скрытые параметры в ноль и отсоединяет их от текущего графа вычислений.

snntorch.utils.valid_split(ds_train, ds_val, split, seed=0)[source]

Случайно разделяет набор данных на непересекающиеся новые наборы заданной длины. При необходимости фиксирует генератор для воспроизводимых результатов. Работает аналогично random_split from torch.utils.data.dataset но сохраняет атрибуты данных и целей.

Example

from snntorch import utils
from torchvision import datasets

data_path = "path/to/data"
val_split = 0.1

#  Download MNIST training set into mnist_val and mnist_train
mnist_train = datasets.MNIST(data_path, train=True, download=True)
mnist_val = datasets.MNIST(data_path, train=True, download=True)

print(len(mnist_train))
>>> 60000

print(len(mnist_val))
>>> 60000

#  Validation split
mnist_train, mnist_val = utils.valid_split(mnist_train,
mnist_val, val_split)

print(len(mnist_train))
>>> 54000

print(len(mnist_val))
>>> 6000
Параметры:

  • ds_train (torchvision dataset) – Обучающий набор

  • ds_val (torchvision dataset) – Проверочный набор

  • split (Float) – Доля образцов, назначаемых проверочному набору из обучающего набора

  • seed (int, необязательный) – Фиксирует генератор для воспроизводимых результатов, по умолчанию 0

Возвращает:

Случайно разделить обучающий и проверочный наборы

Тип возврата:

list of torch.utils.data
