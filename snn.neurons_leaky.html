snn.Leaky

class snntorch._neurons.leaky.Leaky(beta, threshold=1.0, spike_grad=None, surrogate_disable=False, init_hidden=False, inhibition=False, learn_beta=False, learn_threshold=False, reset_mechanism='subtract', state_quant=False, output=False, graded_spikes_factor=1.0, learn_graded_spikes_factor=False, reset_delay=True)[source]

Базовые классы: LIF

Модель нейрона первого порядка с утечкой, интеграцией и срабатыванием. Предполагается, что входные данные представляют собой инъекцию тока. Мембранный потенциал экспоненциально затухает с коэффициентом beta. Для \(U[T] > U_{\rm thr} ⇒ S[T+1] = 1\).

Если reset_mechanism = “subtract”, то \(U[t+1]\) будет иметь порог вычитаемый из него всякий раз, когда нейрон генерирует спайк:

\[U[t+1] = βU[t] + I_{\rm in}[t+1] - RU_{\rm thr}\]

Если reset_mechanism = “zero”, то \(U[t+1]\) будет установлено в 0 всякий раз, когда нейрон генерирует спайк:

\[U[t+1] = βU[t] + I_{\rm syn}[t+1] - R(βU[t] + I_{\rm in}[t+1])\]

  • \(I_{\rm in}\) - Входной ток

  • \(U\) - Мембранный потенциал

  • \(U_{\rm thr}\) - Мембранный порог

  • \(R\) - Механизм сброса: если активен, \(R = 1\), в противном случае \(R = 0\)

  • \(β\) - Скорость затухания мембранного потенциала

Пример:

import torch
import torch.nn as nn
import snntorch as snn

beta = 0.5

# Define Network
class Net(nn.Module):
    def __init__(self):
        super().__init__()

        # initialize layers
        self.fc1 = nn.Linear(num_inputs, num_hidden)
        self.lif1 = snn.Leaky(beta=beta)
        self.fc2 = nn.Linear(num_hidden, num_outputs)
        self.lif2 = snn.Leaky(beta=beta)

    def forward(self, x, mem1, spk1, mem2):
        cur1 = self.fc1(x)
        spk1, mem1 = self.lif1(cur1, mem1)
        cur2 = self.fc2(spk1)
        spk2, mem2 = self.lif2(cur2, mem2)
        return mem1, spk1, mem2, spk2
Параметры:

  • beta (float или torch.tensor) – скорость затухания мембранного потенциала. Ограничена между 0 и 1 во время прямого прохода. Может быть одноэлементным тензором (т.е. одинаковая скорость затухания для всех нейронов в слое) или многозначным (один вес на нейрон).

  • порог (float, необязательный) – Порог для \(mem\) достижения для генерации спайка S=1. По умолчанию 1

  • spike_grad (функция суррогатного градиента из snntorch.surrogate, необязательный) – Суррогатный градиент для члена dS/dU. По умолчанию None (соответствует суррогатному градиенту ATan. См. snntorch.surrogate для дополнительных вариантов)

  • surrogate_disable (bool, Optional) – Отключает суррогатные градиенты независимо от spike_grad аргумента. Полезно для совместимости с ONNX. По умолчанию False

  • init_hidden (bool, необязательный) – Создает переменные состояния как переменные экземпляра. По умолчанию False

  • inhibition (bool, необязательный) – Если True, подавляет все спайки, кроме нейрона с наивысшим состоянием. По умолчанию False

  • learn_beta (bool, необязательный) – Опция для включения обучаемого beta. По умолчанию False

  • learn_threshold (bool, необязательный) – Опция для включения обучаемого порога. По умолчанию False

  • reset_mechanism (str, необязательный) – Определяет механизм сброса, применяемый к \(mem\) каждый раз при достижении порога. Сброс вычитанием: «subtract», сброс до нуля: «zero», нет: «none». По умолчанию «subtract»

  • state_quant (функция квантования из snntorch.quant, необязательный) – Если указано, скрытое состояние \(mem\) квантуется в допустимое состояние для прямого прохода. По умолчанию False

  • выход (bool, необязательный) – Если True а также init_hidden=True, состояния возвращаются при вызове нейрона. По умолчанию False

  • graded_spikes_factor (float или torch.tensor) – выходные спайки масштабируются на это значение, если указано. По умолчанию 1.0

  • learn_graded_spikes_factor (bool, необязательный) – Опция для включения обучаемых градуированных спайков. По умолчанию False

  • reset_delay (bool, необязательный) – Если True, спайк возвращается с задержкой на один шаг после достижения порога. По умолчанию True

Входы: input_, mem_0
  • input_ формы (batch, input_size): тензор, содержащий входные данные

    features

  • mem_0 формы (batch, input_size): тензор, содержащий

    начальный мембранный потенциал для каждого элемента в пакете.

Выходы: spk, mem_1
  • spk формы (batch, input_size): тензор, содержащий

    выходные спайки.

  • mem_1 формы (batch, input_size): тензор, содержащий

    следующий мембранный потенциал для каждого элемента в пакете

Обучаемые параметры:
  • Leaky.beta (torch.Tensor) - опциональные обучаемые веса должны быть

    вручную переданы, формы 1 или (input_size).

  • Leaky.threshold (torch.Tensor) - опциональные обучаемые пороги

    должны быть вручную переданы, формы 1 или `` (input_size).
