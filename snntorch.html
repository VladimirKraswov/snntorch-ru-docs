snntorch

Нейроны snnTorch

snntorch разработаны для интуитивного использования с PyTorch, как будто каждый спайковый нейрон является просто ещё одной функцией активации в последовательности слоёв.

Доступны различные классы спайковых нейронов, которые можно просто рассматривать как блоки активации с PyTorch. Каждый слой спайковых нейронов, таким образом, не зависит от полносвязных слоёв, свёрточных слоёв, остаточных соединений и т.д.

Модели нейронов представлены рекурсивными функциями, что устраняет необходимость хранить следы мембранного потенциала для вычисления градиента. Небольшие требования snntorch позволяют эффективно обучать как маленькие, так и большие сети на CPU, где это необходимо. Будучи глубоко интегрированным с torch.autograd, snntorch может использовать возможности ускорения GPU так же, как и PyTorch.

По умолчанию механизм автоматического дифференцирования PyTorch в torch.autograd обнуляет градиентный сигнал графа спайкового нейрона из-за недифференцируемых пороговых функций спайка. snntorch переопределяет градиент по умолчанию, используя snntorch.neurons.Heaviside. Альтернативные варианты существуют в snntorch.surrogate.

В настоящее время нейроны, доступные в snntorch являются вариантами модели нейрона Leaky Integrate-and-Fire:

  • Leaky - Нейрон Leaky Integrate-and-Fire 1-го порядка

  • RLeaky - Как выше, с рекуррентными связями для выходных спайков

  • Synaptic - Нейрон Integrate-and-Fire 2-го порядка (включая синаптическую проводимость)

  • RSynaptic - Как выше, с рекуррентными связями для выходных спайков

  • Lapicque - Модель RC-нейрона Лапика

  • Alpha - Модель мембраны Alpha

Модели нейронов, ускоряющие обучение, требуют передачи данных параллельно. Доступные нейроны включают: * LeakyParallel - Нейрон Leaky Integrate-and-Fire 1-го порядка

Дополнительные модели включают спайковые LSTM и спайковые ConvLSTM:

  • SLSTM - Спайковая долгая краткосрочная память с пороговой обработкой состояния

  • SConv2dLSTM - Спайковая 2D свёрточная ячейка краткосрочной памяти с пороговой обработкой состояния

Как использовать модели нейронов snnTorch

Следующие аргументы являются общими для большинства моделей нейронов:

  • порог - порог срабатывания нейрона

  • spike_grad - функция суррогатного градиента (см. snntorch.surrogate)

  • init_hidden - установка в True скрывает все состояния нейрона как переменные экземпляра для уменьшения сложности кода

  • inhibition - установка в True разрешает срабатывание только нейрона с наибольшим мембранным потенциалом в плотном слое (не для использования в свёртках и т.д.)

  • learn_beta - установка в True делает скорость затухания обучаемым параметром

  • learn_threshold - установка в True делает порог обучаемым параметром

  • reset_mechanism - варианты включают subtract (сброс вычитанием), zero (сброс до нуля), и none (без механизма сброса: т.е., нейрон с утечкой-интегратором)

  • выход - если init_hidden=True, спайковый нейрон будет возвращать только выходные спайки. Установка output=True позволяет также возвращать скрытое состояние(я). Полезно при использовании torch.nn.sequential.

Модели нейронов Leaky integrate-and-fire также включают:

  • beta - скорость затухания мембранного потенциала, ограниченная между 0 и 1 во время прямого прохода. Может быть одноэлементным тензором (одинаковое затухание для всех нейронов слоя) или многозначным (индивидуальные веса на нейрон в слое). Более сложные нейроны включают дополнительные параметры, такие как alpha.

Рекуррентные модели спайковых нейронов, такие как snntorch.RLeaky и snntorch.RSynaptic явно передают выходной спайк обратно на вход. Такие нейроны включают дополнительные аргументы:

  • V - Рекуррентный вес. Может быть одноэлементным тензором (одинаковый вес для всех нейронов слоя) или многозначным тензором (индивидуальные веса на нейрон в слое).

  • learn_V - по умолчанию True, что позволяет V быть обучаемым параметром.

Спайковые нейронные сети могут быть построены с использованием комбинации snntorch и torch.nn пакетов.

Пример:

import torch
import torch.nn as nn
import snntorch as snn

alpha = 0.9
beta = 0.85

num_steps = 100


# Define Network
class Net(nn.Module):
   def __init__(self):
      super().__init__()

      # initialize layers
      self.fc1 = nn.Linear(num_inputs, num_hidden)
      self.lif1 = snn.Leaky(beta=beta)
      self.fc2 = nn.Linear(num_hidden, num_outputs)
      self.lif2 = snn.Leaky(beta=beta)

   def forward(self, x):
      mem1 = self.lif1.init_leaky()
      mem2 = self.lif2.init_leaky()

      spk2_rec = []  # Record the output trace of spikes
      mem2_rec = []  # Record the output trace of membrane potential

      for step in range(num_steps):
            cur1 = self.fc1(x.flatten(1))
            spk1, mem1 = self.lif1(cur1, mem1)
            cur2 = self.fc2(spk1)
            spk2, mem2 = self.lif2(cur2, mem2)

            spk2_rec.append(spk2)
            mem2_rec.append(mem2)

      return torch.stack(spk2_rec), torch.stack(mem2_rec)

net = Net().to(device)

output, mem_rec = net(data)

В приведенном выше примере скрытое состояние mem должно быть инициализировано вручную для каждого слоя. Это можно преодолеть, автоматически создавая экземпляры скрытых состояний нейронов путем вызова init_hidden=True.

В некоторых случаях (например, усеченное обратное распространение во времени) может потребоваться выполнить обратные проходы до того, как все временные шаги завершат обработку. Это требует перемещения цикла по временным шагам из сети в обучающий цикл.

Пример этого показан ниже:

import torch
import torch.nn as nn
import snntorch as snn

num_steps = 100

lif1 = snn.Leaky(beta=0.9, init_hidden=True) # only returns spk
lif2 = snn.Leaky(beta=0.9, init_hidden=True, output=True) # returns mem and spk if output=True


#  Initialize Network
net = nn.Sequential(nn.Flatten(),
                    nn.Linear(784,1000),
                    lif1,
                    nn.Linear(1000, 10),
                    lif2).to(device)

for step in range(num_steps):
   spk_out, mem_out = net(data)

Установка скрытых состояний в переменные экземпляра необходима для вызова nn.Sequential из PyTorch.

При создании экземпляра нейрона он добавляется как элемент списка в переменную класса LIF.instances. Это позволяет отслеживать, какие нейроны используются в сети, и отсоединять нейроны от вычислительного графа.

В приведенных выше примерах скорость затухания мембранного потенциала beta рассматривается как гиперпараметр. Но его также можно настроить как обучаемый параметр, как показано ниже:

import torch
import torch.nn as nn
import snntorch as snn

num_steps = 100

lif1 = snn.Leaky(beta=0.9, learn_beta=True, init_hidden=True) # only returns spk
lif2 = snn.Leaky(beta=0.5, learn_beta=True, init_hidden=True, output=True) # returns mem and spk if output=True


#  Initialize Network
net = nn.Sequential(nn.Flatten(),
                    nn.Linear(784,1000),
                    lif1,
                    nn.Linear(1000, 10),
                    lif2).to(device)

for step in range(num_steps):
   spk_out, mem_out = net(data.view(batch_size, -1))

Здесь, beta инициализируется значением 0.9 для первого слоя и 0.5 для второго слоя. Затем каждый слой рассматривает его как обучаемый параметр, так же как и все остальные веса сети. Если вы хотите иметь обучаемую скорость затухания для каждого нейрона, а не для каждого слоя, следующий пример показывает, как это сделать:

import torch
import torch.nn as nn
import snntorch as snn

num_steps = 100
num_hidden = 1000
num_output = 10

beta1 = torch.rand(num_hidden)  # randomly initialize beta as a vector
beta2 = torch.rand(num_output)

lif1 = snn.Leaky(beta=beta1, learn_beta=True, init_hidden=True) # only returns spk
lif2 = snn.Leaky(beta=beta2 learn_beta=True, init_hidden=True, output=True) # returns mem and spk if output=True

#  Initialize Network
net = nn.Sequential(nn.Flatten(),
                    nn.Linear(784, num_hidden),
                    lif1,
                    nn.Linear(1000, num_output),
                    lif2).to(device)

for step in range(num_steps):
   spk_out, mem_out = net(data.view(batch_size, -1))

Тот же подход, что и выше, можно использовать для реализации обучаемых порогов с помощью learn_threshold=True.

Каждый нейрон имеет возможность подавлять возбуждение других нейронов в том же полносвязном слое. Это можно вызвать, установив inhibition=True при создании экземпляра нейронного слоя. Это еще не реализовано для сетей, отличных от полносвязных слоев, поэтому используйте с осторожностью.

Создает torch.nn.ModuleList из одномерного слоя пакетной нормализации с длиной time_steps. Вход этого слоя такой же, как и у обычного слоя torch.nn.BatchNorm1d.

Пакетная нормализация во времени (BNTT), представленная в: «Revisiting Batch Normalization for Training Low-Latency Deep Spiking Neural Networks From Scratch» Авторы: Youngeun Kim и Priyadarshini Panda Препринт arXiv: arXiv:2010.01729

Оригинальный репозиторий GitHub: https://github.com/Intelligent-Computing-Lab-Yale/ BNTT-Batch-Normalization-Through-Time

Используя нейрон LIF в качестве нейрона по умолчанию для математики, показанной ниже.

Обычно для одного постсинаптического нейрона i мы можем представить его мембранный потенциал \(U_{i}^{t}\) на временном шаге t как:

\[U_{i}^{t} = λ u_{i}^{t-1} + \sum_j w_{ij}S_{j}^{t}\]

где:

  • λ - коэффициент утечки, который меньше единицы

  • j - индекс пресинаптического нейрона

  • \(S_{j}\) - бинарная активация спайка

  • \(w_{ij}\) - вес связи между пре- и постсинаптическими нейронами.

С пакетной нормализацией во времени мембранный потенциал может быть смоделирован как:

\[ \begin{align}\begin{aligned}U_{i}^{t} = λu_{i}^{t-1} + BNTT_{γ^{t}}\\ = λu_{i}^{t-1} + γ _{i}^{t} (\frac{\sum_j w_{ij}S_{j}^{t} - µ_{i}^{t}}{\sqrt{(σ _{i}^{t})^{2} + ε}})\end{aligned}\end{align} \]
Параметры:

  • input_features (int) – количество признаков входных данных

  • time_steps (int) – количество временных шагов SNN

  • eps (float) – значение, добавляемое к знаменателю для численной устойчивости

  • momentum (float) – значение, используемое для вычисления running_mean и running_var

  • affine (bool) – логическое значение, которое при установке в True позволяет слою Batch Norm иметь обучаемые аффинные параметры

Входные данные: input_features, time_steps

  • input_features: то же количество признаков, что и у входных данных

  • time_steps: количество временных шагов для развертывания в SNN

Выходные данные: bntt

  • bntt формы (time_steps): toch.nn.ModuleList из слоев BatchNorm1d для указанного количества временных шагов

Генерирует спайк если mem > threshold, только для наибольшего мембранного потенциала. Все остальные нейроны будут заторможены на этом временном шаге. Возвращает spk.

instances = []
