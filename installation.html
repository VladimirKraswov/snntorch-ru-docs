Установка

Стабильная версия

Чтобы установить snntorch, выполните эту команду в терминале:

$ pip install snntorch

Это предпочтительный способ установки snntorch, поскольку он всегда устанавливает последнюю стабильную версию.

Если у вас не установлен pip установлен, это руководство по установке Python может помочь пройти процесс.

Чтобы установить snntorch с помощью conda:

$ conda install -c conda-forge snntorch

Из исходных кодов

Исходные коды snntorch можно загрузить из репозитория Github.

Вы можете либо клонировать публичный репозиторий:

$ git clone git://github.com/jeshraghian/snntorch

Или загрузить tarball:

$ curl -OJL https://github.com/jeshraghian/snntorch/tarball/master

Получив копию исходного кода, вы можете установить его с помощью:

$ python setup.py install
